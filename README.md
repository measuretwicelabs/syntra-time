# SyntraTime: the phone page

The shop time page for the phone, added to the home screen from Chrome (owner, 17 Nov 2026; Linework `docs/QUOTES_PLAN.md`, section 6b). It began as a proof that one Microsoft sign-in could save a file into `Syntra\Time\` in the owner's OneDrive; the owner tried that on 18 Nov 2026 and it worked. It is now being built, one screen at a time, from the mockups agreed on 19 Nov 2026 (`docs/time_mockups/`).

The files: `index.html` (the frame and the look), `app.js` (the screens), `syntratime.js` (every sum and rule), `store.js` (what the phone keeps and sends), `view.js` (what the screens show, in order), `help.js` (the Help window's words), `ms.js` (the sign-in and the three calls on the Time folder). Built so far: the frame, the sign-in and What happened (screen 7), and starting and stopping a timer: the home screen, what is being timed and one operation (screens 1, 2 and 3) adding or removing a person (3b), the end-of-day box (4), a trip out leaving with its vehicles (5), coming back (5b), one timer opened with its corrections (6), and time typed in afterwards (6b): the whole phone page. The proof's own test file is gone; its tests became the sign-in tests in `tests/ui/u08_time.py`.

- **The source is here**, in `syntraquote/time/`. The page people open lives in the public repository `measuretwicelabs/syntra-time` (GitHub Pages), which is a copy of this folder. Change it here, test it, then copy it there.
- **It holds no secret and no data of the owner.** `CLIENT_ID` in `index.html` is the public number of the registration with Microsoft: it is meant to be seen and opens nothing by itself. There is no password, key or "client secret" anywhere, and none is needed: the sign-in is Microsoft's own page, with a code that only the phone that asked can use (PKCE).
- **Where it saves** is given once in the set-up link, after the `#` (so it is sent to no server), and kept on the phone: `https://measuretwicelabs.github.io/syntra-time/#folder=<the Syntra folder inside OneDrive>`. The test file is `<that folder>/Time/test-<day>-<time>.json`.
- **What it asks Microsoft for:** to read and write the owner's OneDrive files (`Files.ReadWrite`) and to stay signed in (`offline_access`). Nothing else.
- **The registration** (once, by the owner): an app registration named SyntraTime, for personal Microsoft accounts only, with one redirect address of the kind "Single-page application": the page's own address. Microsoft now wants an Azure account for this (free; it asks for a card to check who you are; a registration costs nothing).
- **The logic of the real page** (19 Nov 2026, chat "SyntraTime 01: the data shape") is `syntratime.js` in this folder: the diaries, the timers, the end-of-day check, the lists, the totals. One file, run on the page, in SyntraQuote and in Node (`tests/node/time.test.js`); its shape is in `docs/DATA.md`, "SyntraTime". It is in this folder so the published copy carries it. The proof page does not use it yet; the screens come next.
- **Test:** `python tests/ui/u08_time.py` (the frame and the sign-in) and `python tests/ui/u12_time_start.py` (starting and stopping) and `python tests/ui/u13_time_people.py` (the names) and `python tests/ui/u14_time_endofday.py` (the end-of-day box) and `python tests/ui/u15_time_trip_out.py` (a trip leaving) and `python tests/ui/u16_time_trip_back.py` (a trip coming back) and `python tests/ui/u17_time_one_timer.py` (one timer opened) and `python tests/ui/u18_time_after.py` (time typed in afterwards) and `python tests/ui/u22_time_typed_job.py` (a job typed once, picked again), with a pretend Microsoft. Not tested: the real sign-in on the real phone, how long the phone stays signed in (a page like this is given a pass that Microsoft renews for about a day at a time; after that it should renew by itself from the phone's Microsoft sign-in, and the proof is there to find out), and working with no signal (that comes with the real page).
