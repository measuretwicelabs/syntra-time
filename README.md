# Syntra Time

The shop time page for the phone. For now it is only a proof: after one Microsoft sign-in it saves a small test file into the owner's own OneDrive folder.

- This repository is public so that a phone can open the page. It holds no data and no secret: no password, no key, no file of anybody's.
- It is a published copy. The source and its test are kept with the quoting program; change it there, then copy it here.
- The page is opened at https://measuretwicelabs.github.io/syntra-time/
